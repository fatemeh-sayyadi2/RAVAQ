# رَواق (RAVĀQ) — فروشگاه آنلاین آجیل، شیرینی سنتی، صنایع‌دستی و هدایای ایرانی

**رَواق (RAVĀQ)** یک وب‌اپلیکیشن فروشگاهی تمام‌عیار (Full-Stack)، فارسی‌محور (RTL) و الهام‌گرفته از معماری و هنر بسته‌بندی اصیل ایرانی است که در پنج حوزه اصلی فعالیت می‌کند:
1. **آجیل و خشکبار** (`آجیل و خشکبار`)
2. **شیرینی‌های سنتی** (`شیرینی‌های سنتی`)
3. **زعفران و خوراکی‌های منتخب** (`زعفران و خوراکی‌های منتخب`)
4. **صنایع‌دستی ایرانی** (`صنایع‌دستی ایرانی`)
5. **جعبه‌های هدیه و پک‌های مناسبتی** (`جعبه‌های هدیه`)

---

## ۱. ویژگی‌های معماری و فنی

- **رابط کاربری فارسی و راست‌به‌چپ (RTL-First):** طراحی‌شده با پالت رنگی اختصاصی رواق (`#F8F4EC` عاجی گرم، `#EFE5D6` کرم، `#742E3A` زرشکی/شرابی، `#4C202B` شرابی تیره، `#2D8C88` فیروزه‌ای ایرانی، `#B89A62` طلایی کهنه و `#292624` زغالی گرم) و خانواده تایپوگرافی `Arad` و `Ganjnameh`.
- **سکشن Hero تمام‌صفحه («بانوی رَواق»):** طراحی اختصاصی تمام‌صفحه (`100svh`) با ترکیب‌بندی مجزا برای دسکتاپ (عریض، کاراکتر در یک‌سوم راست و فضای منفی تایپوگرافی در چپ) و موبایل (عمودی) همراه با جعبه هدیه زرشکی-عاجی منقش به لوگوتایپ واقعی وکتور `رَواق / RAVĀQ`.
- **کاتالوگ کامل ۴۴ محصول اصیل ایرانی:** دارای تصاویر چندحالته (`primary`, `detail`, `packaging`, `lifestyle`)، انتخابگر وزن/سایز (Variants)، مشخصات منشأ، شرایط نگهداری و ترکیبات.
- **موتور موجودی جعبه‌های هدیه (Bundle Inventory Engine):** محاسبه پویا و دقیق موجودی جعبه‌های هدیه بر اساس کمترین موجودی اقلام تشکیل‌دهنده (`min(variantStock, min(childStock / requiredQty))`) و کسر هم‌زمان (تراکنشی) موجودی جعبه و اقلام درونی هنگام تأیید پرداخت.
- **درگاه پرداخت آزمایشی شبیه‌سازی‌شده (Simulated Test Payment Gateway):**
  - ماشین وضعیت کامل: `PENDING` $\rightarrow$ `SUCCEEDED` | `FAILED` | `CANCELLED` | `EXPIRED`
  - جلوگیری از ثبت سفارش تکراری با کلید یکتا (`idempotencyKey`)
  - جلوگیری از کسر موجودی مضاعف در بارگذاری مجدد صفحه نتیجه (`idempotentReplay`)
  - تشخیص و رد مغایرت مبلغ پرداخت (`expectedAmount` Tamper Rejection)
  - امکان ایجاد تلاش پرداخت مجدد (`Retry Payment Attempt`) برای سفارش‌های ناموفق یا لغوشده
- **احراز هویت و کنترل دسترسی سرور-محور (RBAC):**
  - پشتیبانی از ورود با حساب گوگل (Firebase Authentication) و حساب‌های آزمایشی
  - محافظت از سفارش‌های مشتریان در برابر دسترسی سایر کاربران (Customer Ownership Check)
  - پنل مدیریت یکپارچه (`/admin/*`) محافظت‌شده در سمت سرور برای مدیریت محصولات، سفارش‌ها، انبار، کوپن‌ها و دیدگاه‌ها

## ۲. راه‌اندازی و اجرا

### پیش‌نیازها
- Node.js نسخه ۲۰ یا بالاتر
- npm

### نصب وابستگی‌ها
```bash
npm install
```

### اجرای سرور توسعه (Express + Vite بر روی پورت 3000)
```bash
npm run dev
```

### اجرای تست‌های خودکار (Vitest)
```bash
npm test
```

### ساخت نسخه نهایی (Production Build)
```bash
npm run build
npm start
```
